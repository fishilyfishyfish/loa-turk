# LOA 튀르크

*A Lines of Action board game against **Turk**, a game-tree search engine written in plain JavaScript (alpha-beta search in a Web Worker, evaluation tuned by self-play). Play it at https://fishilyfishyfish.github.io/loa-turk/*

Lines of Action 엔진 **튀르크**와 두는 웹 게임. `index.html` 파일 하나로 돌아간다. 설치할 것 없이 브라우저로 열면 된다.

## 하는 법

1. 판 아래에서 **흑 · 선공** 또는 **백 · 후공**을 고른다.
2. 내 말을 누르면 갈 수 있는 칸이 점으로 나온다. 원은 상대 말을 잡는 칸이다.
3. 엔진은 한 수에 5초 생각한다. 내 차례에도 미리 생각한다.
4. **새 게임**을 누르면 처음부터 다시 고른다.

## 학습판

`study.html`은 LOA를 배우는 용도의 따로 된 페이지다. 주소는 https://fishilyfishyfish.github.io/loa-turk/study.html 이다.

- **대국**: 튀르크와 두면서 추천 수 3개와 이유를 볼 수 있고, 내가 둔 수마다 최선부터 블런더까지 6단계로 채점된다. 무르기가 되고, 끝나면 복기로 넘어간다.
- **분석**: 양쪽 수를 직접 두면서 좋은 수 3개와 평가 바를 본다. 기보를 눌러 앞뒤로 오갈 수 있다.
- **퍼즐**: 1수·2수·3수 안에 연결하는 문제 54개. 전부 따져봐서 정답 첫 수가 하나뿐인 문제만 넣었다.

## 규칙

컴퓨터 올림피아드가 쓰는 규칙(2000 MSO 기준)을 따른다.

- 8×8 판. 흑은 위·아래 줄, 백은 왼쪽·오른쪽 줄에 6개씩. 흑이 먼저 둔다.
- 가로·세로·대각선으로 움직인다. 움직이는 칸 수는 그 줄 전체에 놓인 말 수(양쪽 모두, 자기 포함)와 같다.
- 내 말은 뛰어넘을 수 있고 상대 말은 못 넘는다. 상대 말이 있는 칸에 멈추면 잡는다.
- 내 말 전부가 가로·세로·대각선으로 맞닿아 한 덩어리가 되면 이긴다. 말이 하나만 남아도 한 덩어리다.
- 한 수로 양쪽이 동시에 한 덩어리가 되면 무승부. 둘 수가 없으면 차례를 넘긴다. 같은 국면이 같은 차례로 세 번 나오면 무승부.

## 엔진

- 탐색: 알파베타(PVS), 치환표, 킬러·히스토리 수 정렬, 널무브, 후반 수 줄이기(LMR), 반복 심화
- 상대가 다음 수에 연결하는 위협은 탐색 끝에서도 끝까지 확인한다.
- 평가: 말의 뭉침, 덩어리 수, 칸 위치 등 24개 항목. 가중치는 자기대국 약 9만 국면의 승패로 자동 튜닝했다.
- 검증: 무작위 대국 29만 국면에서 참조 구현과 합법수 855만 개를 대조해 불일치 0개.
- 같은 시간 조건에서 옛날 방식 엔진(집중도·덩어리·중앙 평가 + 기본 알파베타)에게 100판 98:2.

## 이름

1770년에 만들어진 체스 두는 자동인형 "튀르크"에서 따왔다. 그건 상자 안에 사람이 숨어서 뒀지만, 이건 진짜 기계다.
